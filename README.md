# RideShare Backend

A scalable ride-sharing backend built with Java, Spring Boot, and PostgreSQL.

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Maven
- REST APIs

## Current Features

- User CRUD APIs
- Request validation
- Global exception handling
- Structured API error responses
- User email uniqueness validation

## Project Status

🚧 Currently under development.

## Planned Features

- Ride management
- Driver and rider workflows
- Authentication & authorization
- Redis caching
- Testing
- Docker
- API Gateway / microservices
